# Sync prototype

Sync is a music dating app: you match on taste, and a Claude agent called Cue explains the match and helps start the chat. This is the prototype for an ITB midterm.

- Explainer with the prototype built in: https://surfinchad.github.io/sync-prototype/
- The prototype on its own (best on a phone): https://surfinchad.github.io/sync-prototype/demo.html

It runs in demo mode: the tools are real and Cue's wording is scripted, so no AI model answers and no key is needed. The members and their chats are fictional. Album art and 30 second previews come from Apple's public iTunes Search API. A song that only lives on SoundCloud can be added by pasting its link (You tab, Add a song); it plays in SoundCloud's own player and links back to the uploader.

Also in the prototype: in a chat you can send a song with one line (Cue can propose the song and the line). On the You tab you can add the gigs you are going to, and a gig is shown only when you and someone else both go (the demo gigs are placeholders, not real events). You can also import your own listening history (You tab, Import): a Spotify data download, read in your browser and never uploaded, or a ListenBrainz account's public stats. "Try a made-up sample" needs no file or account.
